# 시가 타임 (Sigar-time)

회사원들을 위한 가상 담배 타임. 진짜 담배 대신 화면 속 한 개비를 피우며 쉬어요.

- 화면을 꾹 누르면 불이 붙고, 다시 꾹 누르면 들이마시고, 떼면 연기를 내뱉어요.
- 두 번 톡 치면 재를 털어요.
- 아래 칸에 한마디 쓰면 접속한 모든 사람 화면에 연기처럼 떠오르다 약 10초 뒤 사라져요.
- 회원가입 없음, 닉네임 자동 부여, **메시지는 어디에도 저장되지 않아요.**

## 구조

| 부분 | 기술 |
|---|---|
| 화면 | `index.html` 한 파일 (Canvas 2D로 담배·연기·글자 렌더링) |
| 실시간 전달 | 공개 MQTT 중계 서버 `broker.emqx.io` (WebSocket) |
| 호스팅 | GitHub Pages |

## 주의

공개 중계 서버라 같은 토픽 이름을 아는 사람은 메시지를 볼 수 있어요. 민감한 내용은 쓰지 마세요.
토픽 이름은 `index.html`의 `TOPIC` 값에서 바꿀 수 있어요.
